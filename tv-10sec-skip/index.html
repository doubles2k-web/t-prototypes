← / → 키를 누르고 있어보세요

키보드 방향키(←/→)를 눌렀다 떼거나, 누른 채로 유지해보세요.

인터랙션 스펙

Trigger
리모컨 좌/우 방향키 (ArrowLeft / ArrowRight)
등장 — keydown (0.4s)
opacity 0→1, scale 80%→100%
cubic-bezier(0,0,0.2,1)
유지 — 키를 누르고 있는 동안
opacity 100%, scale 100%로 고정 (깜빡임 없이 계속 떠 있음). 키를 얼마나 오래 누르고 있든 이 상태 유지
소멸 — keyup (0.4s)
opacity 1→0, scale 100%→116%로 퍼지며 사라짐
cubic-bezier(0,0,0.2,1)
짧게 탭했을 때
등장 애니메이션이 끝나자마자(0.4s 후) 바로 소멸 시작 → 총 0.8s로 기존과 동일하게 재생
연타 / 재홀드 시
진행 중인 애니메이션을 즉시 중단하고 처음(80%)부터 재시작
